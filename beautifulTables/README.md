# Beautiful Tables Mastery Lab

An interactive React + Tailwind CSS v4 project designed to teach you how to build modern, Linear/Stripe-grade data tables from the ground up.

## Quick Start

```bash
cd beautifulTables
npm install
npm run dev
```

## How to Use This Lab
1. **Start at Tab `0. Visual Guide (8 Rules)`**: Toggle individual design rules ON and OFF on a live table to see how a raw 1995 HTML table transforms into a sleek SaaS interface.
2. **Use the Built-In Mode Switcher (`🛠️ Your Workspace` / `✨ Target Design` / `⚖️ Split Compare`)**:
   - On every Lesson and Question, you can preview the exact finished table (`✨ Target Design`) or compare your table right above the target (`⚖️ Split Compare`) without spoiling the solution code in your workspace file!
3. **Work Through `src/lessons/` (Steps 1–5)**: Refactor ugly/incomplete tables step-by-step.
4. **Conquer `src/questions/` (Questions 1–6)**: Build 6 real-world tables from scratch (including custom hooks and TanStack Query integration in Q4 & Q6).
